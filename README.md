# Engineering Study

Rails・Webバックエンド開発・基本情報技術者試験の学習を継続し、問題の出題、回答、解説、復習、習熟度分析を管理するためのリポジトリです。

## 目的

ChatGPTを学習支援ツールとして利用し、GitHubに学習データを蓄積することで、過去の学習内容を踏まえた継続的な出題と分析を可能にします。

ChatGPTの会話履歴やメモリだけに依存せず、問題文、回答、解説、間違えた理由、ヒントの利用状況を保存します。

これにより、次のことを目指します。

- 過去に解いた問題と回答過程を後から確認できる
- 苦手分野や理解不足の原因を把握する
- 習熟度に応じて問題の難易度を調整する
- 間違えた問題を適切な間隔で復習する
- 日次・週次の成績や学習の進歩を分析する
- ChatGPTの会話が変わっても学習を継続できる

最終的な目標は、正答率を上げることだけではなく、**コードの動作や技術的な仕組みを自分の言葉で説明し、実装に応用できる力を身につけること**です。

## 各ファイルの役割

### README.md

リポジトリの目的、構成、運用方法を説明するファイルです。

### AGENTS.md

ChatGPTなどのAIエージェントに守ってほしい学習ルールを定義します。

主な内容：
- 問題の出題方法
- 回答後の解説方法
- 正解・不正解の判定基準
- ヒントの出し方
- 学習履歴の保存方針
- 復習問題の作成方針

※ ChatGPTが常に自動で読み込むことを保証するものではありません。リポジトリを参照する際の共通指示書として使用します。

### config/curriculum.yml

学習対象と毎日の出題構成を管理します。

現在の出題構成：

| 分野 | 問題数 |
|---|---:|
| Web・Rails | 2 |
| DB・SQL | 2 |
| セキュリティ・認証認可 | 2 |
| 基本情報技術者試験（技術系） | 2 |
| アルゴリズム・Ruby実装 | 2 |
| **合計** | **10** |

### config/difficulty.yml

問題の難易度基準と調整ルールを管理します。

Railsは既存の基礎問題集を参考に、コード読解や動作予測を重視します。

アルゴリズムは、配列・条件分岐・繰り返し処理などの基礎から段階的に難易度を上げます。

### questions/

出題した問題そのものを保存するディレクトリです。

保存する情報：
- 問題ID、出題日、分野、難易度
- 問題文、コード、選択肢
- 正解とその理由
- 不正解の選択肢の解説
- 実装問題の期待する動作や解答例

例：`questions/2026-10-17.yml`

### attempts/

実際の回答履歴を保存するディレクトリです。

保存する情報：
- 対応する問題ID
- 初回回答と正誤
- 再回答や修正したコード
- 提示されたヒント
- 最終的な到達状況
- 間違えた理由や理解が不足していた点

例：`attempts/2026-10-17.yml`

問題データと回答履歴を分けることで、同じ問題を復習した際の成績も追跡できます。

### progress/skills.yml

分野・技術項目ごとの習熟度を管理します。

回答履歴をもとに、正答率、苦手分野、理解度の変化などを記録します。

このファイルは集計結果であり、元データは `questions/` と `attempts/` に保存します。

### progress/review_queue.yml

今後復習する項目と出題予定を管理します。

例えば、Rubyの変数スコープで間違えた場合、一定期間後に別の問題形式で理解度を確認するために利用します。

### reports/weekly/

週次の学習レポートを保存します。

主な内容：
- 分野別の初回正答率
- ヒント後の到達状況
- 前週からの改善点
- 継続している苦手分野
- 次週の復習優先項目

## 学習の流れ

1. ChatGPTが学習設定と過去の記録を参照する
2. 習熟度に応じた問題を1問ずつ出題する
3. 回答後に正誤と全選択肢の解説を行う
4. 必要に応じて段階的なヒントを提示する
5. 問題と回答過程をGitHubに保存する
6. 回答履歴をもとに習熟度と復習予定を更新する
7. 週次レポートで学習状況を振り返る

## 運用上の注意

GitHubを学習記録の正本として扱います。

ChatGPTによるGitHubの参照・更新には、対応する接続環境が必要です。毎朝の自動出題とGitHubへの記録が完全に連動する仕組みは、今後検証・構築します。

また、過去の問題文や回答履歴が確認できない場合は、推測で補完せず、記録が不足していることを明示します。
